## ✅ Задачи для AI:

### Шаг 1: Анализ
1. Прочитай все измененные файлы
2. Определи какие из 5 модулей затронуты:
   - 01_CORE_SETUP.md (БД, базовый backend/frontend)
   - 02_DASHBOARD_PAGE.md (дашборд)
   - 03_SEARCH_QUEUE_PAGE.md (поисковая очередь)
   - 04_VIDEO_QUEUE_PAGE.md (видео очередь)
   - 05_SETTINGS_PAGE.md (настройки)

### Шаг 2: Обновление

1. Найди соответствующую секцию в промпт-файле
2. Обнови код/текст с учетом изменений
3. **ВАЖНО:** Сохрани всю детализацию (не сокращай код)
4. **ВАЖНО:** Сохрани стиль (комментарии, форматирование)
5. Проверь что код синхронен между модулями (если одно и то же используется в разных местах)

### Шаг 3: Дополнительные обновления
1. Обнови Testing Checklist если добавлены новые функции
2. Обнови статистику в README.md (количество endpoints, компонентов)
3. Обнови "Install Additional Dependencies" если добавлены npm пакеты

### Шаг 4: Проверка
1. Убедись что промпт-файлы содержат ПОЛНЫЙ код (не сокращенный)
2. Убедись что все новые зависимости перечислены
3. Убедись что Testing Checklist актуален

---

## ⚙️ Требования к обновлениям:

✅ **Делай:**

## 🔍 Как использовать шаблоны

### Шаг 1: Выбери нужный шаблон
- Главный шаблон - для любых изменений
- Быстрые шаблоны (1-7) - для конкретных случаев

### Шаг 2: Заполни параметры
Замени все `[...]` на свои данные:
- `[название модели]` → `VideoQueue`
- `[путь к файлу]` → `web/src/components/NewComponent.tsx`
- `[вставь код]` → вставь реальный код из файла

### Шаг 3: Дай промпт AI
Скопируй заполненный шаблон и дай Claude Code или другому AI

### Шаг 4: Проверь результат
```bash
# Посмотри что изменилось
git diff docs/prompts/app/

# Убедись что изменения корректны
# Закоммить
git add docs/prompts/app/
git commit -m "docs: sync prompts with [описание изменений]"
```

### Пример 2: Добавили endpoint для экспорта в Excel

```markdown
Добавил новый API endpoint:

**Метод:** GET
**Путь:** /api/video-queue/export/excel
**Описание:** Экспорт видео очереди в Excel формат (.xlsx)

**Код endpoint:**
```javascript
app.get('/api/video-queue/export/excel', async (req, res) => {
  try {
    const videos = await prisma.videoQueue.findMany({
      orderBy: { createdAt: 'desc' }
    });

    const workbook = XLSX.utils.book_new();
    const worksheet = XLSX.utils.json_to_sheet(videos);
    XLSX.utils.book_append_sheet(workbook, worksheet, 'Videos');

    const buffer = XLSX.write(workbook, { type: 'buffer', bookType: 'xlsx' });

    res.setHeader('Content-Type', 'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet');
    res.setHeader('Content-Disposition', 'attachment; filename=video-queue.xlsx');
    res.send(buffer);
  } catch (error) {
    console.error('Error exporting to Excel:', error);
    res.status(500).json({ error: 'Failed to export to Excel' });
  }
});
```

**Задача:**
1. Определи к какому модулю относится endpoint (04_VIDEO_QUEUE_PAGE.md)
2. Вставь код в секцию "API Endpoints"
3. Вставь ПОСЛЕ endpoint GET /api/video-queue/export
4. Добавь описание что endpoint делает
5. Добавь пункт в Testing Checklist: "Export to Excel creates valid .xlsx file"
6. Добавь npm пакет в dependencies: npm install xlsx

Начни с определения модуля.
```

## 📦 Автоматизация

### Скрипт для генерации списка измененных файлов

Добавьте в `package.json`:

```json
{
  "scripts": {
    "changed": "git diff --name-only HEAD"
  }
}
```

Использование:
```bash
npm run changed
# Скопируй вывод и вставь в шаблон промпта
```

## ✨ Best Practices

### ✅ ВСЕГДА делай:
1. **Полный код** - никаких сокращений типа "// ... rest of code"
2. **Комментарии** - сохраняй все комментарии из исходного кода
3. **TypeScript типы** - все интерфейсы и типы должны быть в промптах
4. **Зависимости** - указывай все новые npm пакеты
5. **Testing Checklist** - обновляй при добавлении функций

### ❌ НИКОГДА не делай:
1. **Сокращения кода** - промпты должны содержать код готовый к copy-paste
2. **Забывать про зависимости** - каждый npm пакет должен быть указан
3. **Смешивать старое и новое** - при рефакторинге заменяй полностью
4. **Терять синхронизацию** - обновляй промпты сразу после изменений в коде
