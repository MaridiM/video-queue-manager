# Промпты для генерации документации

Эта директория содержит промпты, используемые для генерации документации Queue Manager с помощью AI.

## 📋 Содержание

### [00_PROJECT_OVERVIEW.md](./00_PROJECT_OVERVIEW.md)
**Обзор проекта**
- Общее описание Queue Manager
- Функциональные и технические требования
- Основные компоненты системы
- Используется для генерации общей документации проекта

### [01_BACKEND_ARCHITECTURE.md](./01_BACKEND_ARCHITECTURE.md)
**Backend архитектура**
- Структура API сервера
- Технический стек
- Основные компоненты и endpoints
- Используется для генерации [BACKEND.md](../BACKEND.md)

### [02_FRONTEND_ARCHITECTURE.md](./02_FRONTEND_ARCHITECTURE.md)
**Frontend архитектура**
- Структура React приложения
- Компоненты и страницы
- State management
- Используется для генерации [FRONTEND.md](../FRONTEND.md)

### [03_DATABASE_SCHEMA.md](./03_DATABASE_SCHEMA.md)
**Схема базы данных**
- Модели данных Prisma
- Связи между таблицами
- Миграции
- Используется для генерации [DATABASE.md](../DATABASE.md)

### [04_INTEGRATIONS.md](./04_INTEGRATIONS.md)
**Интеграции**
- Dropbox API интеграция
- AI провайдеры (Google AI, OpenAI)
- YouTube API (Innertube)
- Используется для дополнения документации по интеграциям

### [05_COMPLETE_APP_GENERATION_PROMPT.md](./05_COMPLETE_APP_GENERATION_PROMPT.md) ⭐

**Полный промпт для генерации приложения**

- **Размер:** 62KB, 8000+ строк
- Комплексный промпт для воссоздания всего приложения с нуля
- Включает полный технический стек, архитектуру, все API endpoints
- Полный код компонентов, базы данных, бизнес-логики
- Конфигурация, развертывание, безопасность
- **Использование:** Для генерации приложения с другим AI (ChatGPT, Claude и т.д.)

### [06_APP_ANALYSIS_SUMMARY.md](./06_APP_ANALYSIS_SUMMARY.md) 📊

**Краткий анализ приложения**

- **Размер:** 12KB
- Исполнительное резюме проекта
- Статистика кодовой базы (8000+ строк кода)
- Обзор архитектуры и ключевых функций
- Оценка зрелости проекта и рекомендации
- **Использование:** Быстрый обзор приложения для новых разработчиков

---

## 🎯 Использование

Эти промпты можно использовать с AI ассистентами (например, Claude, GPT-4) для генерации или обновления документации проекта.

### Пример использования:

```
Используй промпт из docs/prompts/01_BACKEND_ARCHITECTURE.md 
для генерации/обновления документации BACKEND.md
```
