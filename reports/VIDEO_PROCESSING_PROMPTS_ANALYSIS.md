## 🎬 Промпты для транскрипции видео

### PMT-004: Video Transcription v4.1
**Файл:** `ENTITIES/PROMPTS/PMT-004_Video_Transcription_v4.1.md`  
**Версия:** 4.1-TASK_MANAGERS  
**Дата:** 2025-11-19  
**Статус:** Активный

**Назначение:**
Основной промпт для транскрипции видео с фокусом на извлечение сущностей TASK_MANAGERS (Milestones, Tasks, Steps) с использованием словаря LIBRARIES для таксономического маппинга.

**Ключевые возможности:**
- Полная транскрипция слово-в-слово с временными метками
- Извлечение метаданных (название, канал, URL, дата публикации)
- Идентификация Milestones (MLS-###) - кластеры последовательных задач
- Идентификация Tasks (TSK-###) - отдельные задачи
- Идентификация Steps (STP-###) - атомарные шаги
- Извлечение глаголов действий (7 категорий: A-G)
- Матрица инструментов и технологий
- Цепи задач (Task Chains)
- Словарь ответственностей
- Вероятностное маппинг Action-Object-Tool
- Иерархические деревья отношений
- Анализ распределения по департаментам
- CSV мастер-лист для TASK_MANAGERS сущностей

**Формат вывода:** Markdown (.md) с 16 секциями

**Использование:**
- Транскрипция видео через AI Studio (Gemini)
- Извлечение структурированных данных для таксономии
- Создание мастер-листов для интеграции в библиотеки

## 🔍 Промпты для анализа видео

### PMT-006: Video Analysis
**Файл:** `ENTITIES/PROMPTS/PMT-006_Video_Analysis.md`  
**Версия:** 1.0  
**Дата:** 2025-11-12  
**Статус:** Активный

**Назначение:**
Комплексное руководство по анализу транскрипций видео для извлечения элементов таксономии и маппинга их в структуру LIBRARIES.

**Ключевые возможности:**
- 3-фазный рабочий процесс анализа:
  - **Фаза 1:** Первичный обзор (15-20 мин)
  - **Фаза 2:** Глубокое извлечение (30-45 мин)
  - **Фаза 3:** Таксономический маппинг (20-30 мин)
- Извлечение инструментов и технологий
- Извлечение рабочих процессов (Workflows)
- Категоризация глаголов действий (5 категорий)
- Извлечение цепей задач (Task Chains)
- Извлечение словаря ответственностей
- Документирование паттернов интеграции
- Расчет метрик покрытия (Coverage %)
- Создание отчетов Gap Analysis

**Метрики успеха:**
- Coverage %: (Существующие элементы / Всего упомянутых) × 100
- Gap Count: Количество отсутствующих записей таксономии
- Quality Score: Полнота извлеченной документации workflow

**Использование:**
- Анализ уже транскрибированных видео
- Извлечение структурированных данных
- Идентификация пробелов в таксономии

### PMT-012: Transcript Processing Workflow
**Файл:** `ENTITIES/PROMPTS/PMT-012_Transcript_Processing_Workflow.md`  
**Версия:** 2.0  
**Дата:** 2025-11-17  
**Статус:** Активный

**Назначение:**
Полный end-to-end рабочий процесс от обнаружения видео через обработку транскрипции до заполнения библиотек.

**3 основных этапа:**

**STAGE 1: Video Discovery & Research** (2-3 часа/неделю)
- Определение фокуса исследований
- Поиск видео (Perplexity AI, YouTube)
- Система оценки релевантности (0-100 баллов)
- Выбор топ 3-5 видео (балл 80+)

**STAGE 2: Video Transcription & Analysis** (40-80 мин/видео)
- Транскрипция видео (Google AI Studio / Transcribe AI)
- Извлечение элементов таксономии (14 секций)
- Глубокий анализ (3 фазы)
- Валидация качества

**STAGE 3: Library Processing & Population** (10-20 мин/видео)
- Сбор и валидация инструментов
- Интеграция Task & Step Templates
- Интеграция Skills
- Обновление маппингов
- Gap Analysis & Reporting

**Ключевые возможности:**
- Еженедельный график работы
- Метрики успеха по этапам
- Чеклисты качества
- Диаграммы потока данных
- Интеграционные точки между этапами

**Экономия времени:** 90-95% сокращение по сравнению с ручной обработкой
